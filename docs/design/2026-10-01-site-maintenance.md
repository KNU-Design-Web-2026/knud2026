# 2026-10-01 임시 준비 중 화면

## 목적

전시 공개 전에는 기존 콘텐츠를 삭제하지 않고, 방문자에게 IGNITE 로고와 전시 일정·장소, 준비 중 안내를 보여준다.

## 동작

- `feat/coming-soon-gate` 브랜치에서는 `SITE_MAINTENANCE_MODE`가 `off`가 아니면 준비 중 화면이 기본으로 켜진다.
- 홈은 공통 헤더·푸터·커서를 제외한 준비 중 화면을 보여준다.
- 기존 전시 페이지와 상세 주소로 직접 접근하면 홈으로 임시 이동한다.
- `/api/*`는 503으로 응답하여 메시지 조회·작성 요청을 처리하지 않는다.
- 준비 중에는 검색 로봇에 `noindex, nofollow`를 알리고 사이트맵은 홈만 제공한다.
- 로컬 개발 중 기존 사이트를 확인할 때는 Git에서 제외되는 `.env.development.local`에 `SITE_MAINTENANCE_MODE=off`를 설정한다.
- 배포 사이트를 공개할 때는 배포 환경에 `SITE_MAINTENANCE_MODE=off`를 설정하고 재배포한다. 기존 페이지와 데이터는 삭제하지 않는다.

## 제한

이는 공개 화면을 가리는 조치이지 인증·비밀번호 보호가 아니다. 이전에 색인된 검색 결과나 직접 주소를 아는 정적 자산까지 비공개로 만들지는 못한다. 완전한 접근 제한이 필요하면 배포 플랫폼의 인증·접근 제어를 별도로 사용해야 한다.

## 2026-10-19 예약 공개

- 자동 공개 시각은 **2026-10-20 09:00:00 한국 시간**이다. 코드에서는 `2026-10-20T09:00:00+09:00`으로 지정하며 UTC로는 10월 20일 00:00이다.
- 앞선 수동 전환 설명을 확장한다. `SITE_MAINTENANCE_MODE=auto` 또는 미설정이면 매 요청의 서버 시각으로 판단한다. `on`은 시각과 관계없이 긴급 차단, `off`는 개발·검수용 즉시 공개다. 알 수 없는 값은 차단한다.
- **운영 배포의 설정은 auto 또는 미설정이어야 한다.** 기존 운영 값이 on이면 계속 차단되며 off이면 미리 공개되므로, 코드와 함께 배포 설정을 확인해야 한다.
- 홈, 공통 레이아웃, 검색 메타데이터, robots.txt, sitemap.xml은 `connection()` 이후 시각을 판단하여 빌드 당시의 준비 중 상태가 정적 캐시에 남지 않도록 한다. 이 때문에 페이지는 요청 시 렌더링하며, 자산·이미지 캐시는 유지한다.
- 직접 경로와 메시지 API의 proxy도 같은 함수를 사용한다. 공개 시각에는 배포나 별도 예약 작업을 실행하지 않는다.
- 이미 열어둔 준비 중 화면을 자동 새로고침하지는 않는다. 정각 이후 새 접속·새로고침부터 정상 사이트를 제공한다.
- 이번 변경은 접근 인증을 우회하지 않는다. Vercel 등 플랫폼의 별도 접근 보호가 켜져 있으면 공개 전 별도로 확인해야 한다.
- 로컬 코드 적용만으로 운영 예약이 완료되는 것은 아니다. 운영 설정과 이 코드가 반영된 배포까지 확인해야 한다.

### 예약 공개 검증

- 시각 경계·수동 모드·proxy 관련 테스트 11개, ESLint, 타입 검사, 프로덕션 빌드, diff 검사 통과.
- 같은 프로덕션 빌드를 두 로컬 서버로 실행했다. 하나는 실제 공개 전 시각, 다른 하나는 테스트 프로세스에서만 Date를 10월 20일 09:00 한국 시간으로 고정했다. 운영 코드에는 테스트용 시각 변경 기능을 넣지 않았다.
- 공개 전: 홈 준비 중, noindex, 직접 경로 307, 메시지 API 503, 홈만 있는 사이트맵을 확인했다.
- 공개 시각: 홈의 main-hero, 직접 경로 200, 메시지 API GET 200, noindex 해제, 전체 사이트맵과 robots의 Sitemap 항목을 확인했다. API POST나 데이터 변경 검증은 하지 않았다.
- 홈 응답은 두 조건 모두 `private, no-cache, no-store, max-age=0, must-revalidate`였으며 빌드 결과에서도 홈·레이아웃·robots·sitemap이 동적 경로로 표시됐다.

## 검수

- 홈의 로고·전시 정보·안내 문구와 모바일·데스크톱 배치를 확인한다.
- 기존 페이지 직접 주소가 홈으로 이동하는지 확인한다.
- API가 503을 반환하는지 확인한다.
- `SITE_MAINTENANCE_MODE=off`에서 기존 사이트가 보이는지 확인한다.
