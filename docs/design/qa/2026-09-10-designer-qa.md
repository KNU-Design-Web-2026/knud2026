## QA-001 — About 소개 문장의 단어 중간 줄바꿈

- 재현: `/about`, 1020 × 1370
- 원인: 소개 문단의 `overflow-wrap: anywhere`가 한글 단어를 음절 단위로 분리했다.
- 결정: 모든 반응형 구간의 소개 문단에 `word-break: keep-all`과 `overflow-wrap: break-word`를 함께 사용한다.
- 결과: `더 큰 가 / 능성`처럼 단어 중간에서 끊기던 문장이 공백을 기준으로 줄바꿈된다.

## QA-002 — 1020px Space 이름 클릭 시 상세 이동

- 결정: 지도 이름을 임시 배정된 작품의 `/work/[id]` 링크로 제공한다.

  - 1350px 초과: 기존 커서 hover·focus·클릭 미리보기를 유지한다.
  - 821px 이하: 기존 세로·가로 compact 지도에서 터치 링크를 유지한다.

## QA-004 — About·Work·Space의 헤더·푸터 인접 여백 통일

- 재현: `/work`, 1920 × 1340 및 Web부터 Mobile까지 전체 반응형 구간
- 원인:
  - Work는 600px 이하에서 페이지 전용 `40px`·`24px` 여백이 Profile 토큰을 덮었다.
  - Space는 화면 폭에 따라 `clamp()`로 최대 `200px`까지 늘어나는 독립 여백을 사용했다.
  - About은 첫 소개 프레임의 절대 위치와 마지막 팀 섹션의 하단 여백이 화면별 고정값으로 분리돼 있었다.
- 결정: 세 페이지 모두 Profile의 `--profile-page-top-gap`에 카드 hover 확장 영역을 고려한 `20px` 시각 보정값을 더한 `--content-page-edge-gap`을 사용한다.
- About 보정: 소개 프레임만 위로 옮겨 내부 구성 간격이 달라지지 않도록, 기존 첫 콘텐츠 위치와 공통 토큰의 차이만큼 소개 섹션 전체 높이도 함께 줄인다.
- 반응형 기준값:
  - 1920px: 위·아래 `100px`
  - 1020px: 위·아래 `80px`
  - 600px: 위·아래 `80px`
  - 400px: 위·아래 `60px`

## 검증

- 1020 × 1370 About: 소개 문단의 계산된 스타일이 `word-break: keep-all`, `overflow-wrap: break-word`인지 확인했다.
- 1020 × 1370 Space: 클릭 안내 노출과 `/work/1` 이동을 확인했다.
- 1350 × 900 Space: 클릭 안내 노출과 상세 이동을 확인했다.
- 1351 × 900 Space: 커서 안내 노출, URL 유지, 미리보기 `aria-expanded=true`를 확인했다.
- 600 × 980 Space: 터치 안내 노출과 compact 지도 링크 이동을 확인했다.
- 1920·1020·600·400px에서 About, Work, Space의 계산된 위·아래 여백이 Profile 기준값보다 각각 `20px` 넓은지 브라우저로 교차 확인했다.
- 관련 About·Work·Space 테스트 44개를 통과했다.

## QA-005 — Message 장문 작성과 수신자 정보 위계

- 대상: `/message`, Web부터 Mobile까지 전체 반응형 구간
- 요청:
  - 카드에 수용할 메시지 최대 길이를 130자로 조정한다.
  - 현재 입력 글자 수와 제한을 작성 박스 좌측 하단에 표시한다.
  - 작성 영역과 입력 글자 크기는 기존 규격을 유지하고, 하단 포스트잇의 본문 밀도만 조정한다.
  - `To.`에서 실제 수신자를 선택하면 이름을 굵게 표시한다.
- 결정:
  - 브라우저의 `maxLength`와 상태 갱신 양쪽에서 130자 제한을 적용한다.
  - 카운터는 `현재 글자 수 / 130` 형식으로 표시하고 입력 영역의 설명과 연결한다.
  - 작성 영역의 크기는 포커스 전후 동일하게 유지한다.
  - 입력창 본문은 모바일 `9~12px`, 태블릿 `12~14px`, 웹 `16~20px`의 기존 유동 크기로 복원한다.
  - 포스트잇 본문은 웹 `22px`, 중간 화면 `20px`, 모바일 `13~15px`로 구분하고 카드 높이에 따라 최대 `6~9줄`을 노출한다.
  - 포스트잇의 고정 정사각형 크기와 `To`·`From` 위치는 유지하며, 남는 본문 공간을 더 사용한 뒤 긴 글만 말줄임 처리한다.
  - 기본값 `전체(모두)`는 regular, 실제 선택 수신자와 카드의 수신자 이름은 bold로 표시한다.
  - 수신자 이름과 하단 화살표는 동일한 flex 행에 두고, 필드 라벨에만 절대 위치를 적용한다.
  - 목업 데이터는 130자 이하의 메시지 8종을 서로 다른 줄바꿈으로 구성한다.
- 검증:
  - 400·600·1020·1350·1920px에서 130자를 입력해 카운터, 입력 제한, 본문 수용 여부를 확인했다.
  - 모든 규격에서 포커스 전후 작성 영역과 입력 글자 크기가 유지되고 카운터와 전송 버튼이 본문과 겹치지 않았다.
  - 하단 포스트잇은 130자 목업에서도 `From` 영역을 침범하지 않고 화면별 최대 줄 수에서 말줄임 처리되는지 확인했다.
  - 모든 규격에서 수신자 이름과 화살표의 계산된 위치가 `static`이며 선택 영역 안에서 수직 중앙 정렬되는 것을 확인했다.
  - 실제 수신자 선택 후 계산된 글꼴 굵기가 `700`으로 변경되는 것을 확인했다.
