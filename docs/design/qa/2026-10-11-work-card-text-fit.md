# 실제 작품명 카드 넘침 수정

상태: 구현 완료, 디자인 검토 요청. 푸시·배포 미진행.

## 원인과 변경

- 작품명을 mock 한 줄에서 실제 긴 제목으로 교체하면서 제목 줄바꿈이 정보 패널 높이를 바꿨다.
- 한글·영문 이름은 고정 간격의 flex 행이었으며 영문 영역에 남은 폭을 할당하지 않아 넘칠 수 있었다.
- 기존 이미지 비율·열 수·패널 패딩·기본 글자 크기는 유지한다.
- 제목은 기존 한 줄 높이를 확보한다. 실제 텍스트 폭이 가용 폭보다 클 때만 글자 크기를 줄여 전체 제목을 표시한다. 말줄임이나 문자열 삭제는 하지 않는다.
- 영문 이름은 한글 이름을 제외한 남은 폭에 맞춰 동일 방식으로 조정한다.
- 브라우저 폭, 컨테이너 크기, 웹폰트 로딩 완료 시 재측정하고 observer·이벤트·예약 프레임은 정리한다.
- 브라우저 측정이 필요한 텍스트 span만 Client Component로 분리한다. 이미지·링크·카드 구성은 Server Component로 유지한다.
- 양혜연 작품명에 포함된 제출용 '(한글 표기 필요할 시 : 무이)' 메모는 목록·상세 제목에서 제외하고 MOOEE만 표시한다. 제출 프로필 원문은 수정하지 않는다.

## 실제 화면 검사

19개 카드 전체를 320·360·390·400·440·600·768·830·831·1020·1280·1350·1351·1440·1920px에서 검사했다.
폰트 맞춤 완료 후 제목·영문 텍스트의 실제 폭이 부모 가용 폭을 넘지 않으며 페이지 가로 넘침도 없다.
각 폭에서 19개 정보 패널의 높이는 모두 동일했다.

| 화면 폭 | 정보 패널 높이(반올림) |
| --- | --- |
| 320~400px 검사 구간 | 49.8px |
| 440·600px | 72.8px |
| 768·830·831·1020px | 81.4px |
| 1280·1350·1351px | 84.0px |
| 1440·1920px | 92.6px |

긴 '대구 떡볶이 페스티벌 리브랜딩', 공동 작품 작가명, 영문 이름을 PC·모바일 실제 화면에서도 확인했다.
폰트가 로딩되는 동안에도 한 줄 박스 높이는 변하지 않는다. JS 비활성 환경에서는 텍스트 맞춤이 실행되지 않으므로 제목 일부가 가려질 수 있으나 전체 제목은 DOM과 상세 보기 접근성 이름에 유지된다.
