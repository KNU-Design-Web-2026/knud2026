# MESSAGE 상단 경계 애니메이션 떨림

## 원인과 변경

- 기존에는 IntersectionObserver가 감지하는 article 자체에 24px translate와 투명도 전환을 적용했다.
- 카드가 화면 상단의 교차 임계값에 걸리면 이동이 감지 결과를 뒤집어 같은 애니메이션을 반복할 수 있다.
- article은 기존 그리드·엇갈림·크기를 유지하는 고정 감지 영역으로 남긴다.
- 배경·본문·To./From.을 포함한 안쪽 surface에만 초기 등장과 스크롤 애니메이션을 적용한다.
- surface는 article의 반응형 padding을 상속하고, 절대 배치로 감지 영역 크기에 영향을 주지 않는다.
- 화면 재진입 시 반복 등장, reduced motion 설정, 숨김 데이터 제외는 유지한다.

## 검증 (2026-10-28, 로컬 Chromium)

- 실제 컴포넌트 서버 렌더링 테스트: 감지 article에 초기 이동 클래스가 있으면 실패한다. 수정 전 실패, 수정 후 통과를 확인했다.
- 로컬 페이지에서 기존 article 이동 CSS를 임시로 재현하고 첫 카드 상단 임계값에 스크롤을 고정: 4초 동안 visible 속성 7회 전환.
- 같은 위치에서 임시 CSS 제거 후 수정 구조: 4초 동안 0회 전환. 이후 페이지 새로고침으로 임시 계측을 제거했다.
- 1920×1080, 390×844, 844×390: 경계 정지 후 2초 관찰에서 추가 전환 0회, 감지 article의 translate는 none.
- 세 뷰포트 모두 149개 카드의 감지 영역과 surface 높이가 같고, From.이 surface 하단 안쪽에 위치하며 가로 넘침이 없다.
- 재진입 확인: visible true → false → true, surface translate 0 → 24px → 0.
- 운영 DB에 테스트 메시지를 작성하지 않았고 배포하지 않았다. Safari/WebKit은 이번 검증에 포함하지 않았다.
