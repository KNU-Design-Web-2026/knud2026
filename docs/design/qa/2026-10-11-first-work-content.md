# 1차 실제 작품 반영

상태: 구현 완료, 디자인 검토 요청. 배포·푸시 미진행.

## 자료와 매칭

원본 폴더: 사용자 제공 Downloads/웹 1차. 원본 파일은 수정하지 않았다.
작품명·분야·연락처는 기존 공개 프로필 시트 데이터를 재사용한다.

| 작가 | 작품 | 상세 경로 | 상세 이미지 수 |
| --- | --- | --- | --- |
| 공예원 | BEOSEOT CLUB | /work/1 | 8 |
| 김연수 | HITOMA | /work/6 | 4 |
| 김은별 | PAPAPA~ | /work/7 | 4 |
| 이초원 | MOA | /work/15 | 7 |
| 조장원 | 단탈리온 | /work/18 | 6 |

Work 목록은 Work 썸네일, SPACE 미리보기는 SPACE 썸네일,
작품 상세와 프로필 Work 영역은 상세 대표 이미지를 사용한다.
SPACE 부스 배정과 홍길동 라벨은 확정 자료가 아니므로 이번 작업에서 변경하지 않았다.
미제출 14개 작품은 기존 mock 상태를 유지한다.

## 이미지 처리

- scripts/import-work-assets.mjs로 작가별 웹 자산과 manifest.json을 생성한다.
- WebP 품질 90, sRGB, 원본 비율 유지, 확대 금지.
- 최대 폭: Work 768px, SPACE 1248px, 대표·상세 1920px.
- 포트폴리오는 파일의 001~번호순으로 정렬하고 CSS 간격 없이 이어 붙인다.
- Next Image의 sizes와 lazy loading을 사용하며 이미지 규격을 지정해 공간을 미리 확보한다.
- 웹 사본 전체 약 11.83MiB, 전달된 PNG 전체 약 122.01MiB.
  이는 파일 합계이며 실제 방문 시 전송량이나 성능 측정 결과는 아니다.
- 각 manifest에 원본 파일명·폭·높이·바이트와 출력 크기를 기록했다.

별도의 작품 소개문/영문 소개문은 제출되지 않았다. 이미지에 포함된 설명을 그대로 보여주며,
해당 5명의 가짜 mock 소개문은 노출하지 않는다. 별도 텍스트를 받으면 소개 영역에 추가한다.
모바일에서 mock 소개문을 위해 예약했던 고정 높이를 실제 제출 작품에서만 해제했다.

## 검증과 검토 필요 사항

- Work·Profile·SPACE 관련 테스트 60개 통과, lint·타입 검사·프로덕션 빌드 통과.
- 360·400·600·1350px에서 5명의 제목·이미지 수·가로 넘침을 확인했다.
- 공예원의 Work 썸네일은 원본이 384×280, SPACE는 624×382다.
  인위적으로 확대하지 않았으므로 고밀도 화면 검토 후 필요하면 고해상도 원본을 요청한다.
- 모바일 글자가 이미지 안에 포함되어 있으므로 실제 기기에서 읽기 쉬운지 디자이너 검수가 필요하다.
- 압축 사본의 색상·텍스트·상세 페이지 간 연결은 최종 시각 검토 대상이다.
