# MESSAGE 공개 메시지 전체 조회

- 요청: 최신 100건을 넘는 이전 메시지도 모두 표시한다.
- 원인: 저장소 조회의 전체 결과가 `limit=100`으로 제한되어 있었다. 화면에는 추가 조회 기능이 없다.
- 변경: 서버에서 100건씩 순차 조회하고 마지막 페이지까지 합쳐 전달한다. 100건은 전체 표시 제한이 아니라 조회 배치 크기다.
- 유지: 최신 작성순 및 동일 시각의 ID 내림차순, `hidden_at is null` 공개 조건, 캐시 미사용.
- DB 데이터·숨김 상태·작성 제한은 변경하지 않는다. 애니메이션 떨림 수정은 별도 작업이다.
- 회귀 검증: 공개 데이터 249건 전체 반환, 순서 유지, 후속 페이지 오류 시 부분 목록을 성공으로 반환하지 않음.
- 메시지가 대규모로 늘면 초기 HTML과 DOM 비용이 증가하므로, 별도 요구 시 전체 기록에 접근 가능한 점진 로딩을 검토한다.
