## 웹 자산

- 기존 가져오기 스크립트 재사용: WebP 품질 90, sRGB, 원본 비율 유지, 작은 원본은 확대하지 않음.
- 최대 폭: Work 768px, SPACE 1248px, 상세 대표·포트폴리오 1920px.
- 현재 반영 대상 2차 원본 합계 1,058,817,543 bytes(약 1009.77MiB), 웹 사본 합계 26,902,126 bytes(약 25.66MiB).
- 파일 합계 비교이며 Lighthouse 결과나 실제 방문 전송량을 의미하지 않는다. 상세는 기존 Next Image sizes·lazy loading을 유지한다.
- 각 작가의 manifest에 원본 파일명·규격·용량과 생성된 웹 사본 규격을 기록했다.

## 검증과 남은 검수

- 실제 임시 PNG 파일을 생성해 가져오기 명령의 용도 구분·숫자 정렬·리소스 포크 제외를 검증하는 테스트 3개를 추가했다. 기존 명령에서 실패한 뒤 수정 후 통과했다.
- 14명의 작품 식별자·대표 이미지·소개·연락처·상세 개수 및 서버 렌더된 상세 이미지 순서를 확인했다. 이나경의 2차 이미지 제외와 기존 소개·연락처 유지 회귀 검사를 추가했다.
- 전체 테스트 158개, lint, 타입 검사, 프로덕션 빌드, diff 검사 통과.
- 모든 생성 파일의 실제 폭·높이와 manifest 일치를 확인했다.
- 이번 작업의 새 브라우저 캡처는 브라우저 접근 제한으로 수행하지 못했다. PC·모바일 실화면 검수는 아직 완료했다고 주장하지 않으며 PR에 명시한다.
- 양혜연·현연이의 Work 원본은 384×280, SPACE는 624×382이므로 고밀도 화면에서 선명도 검토가 필요하다.
- 박수정의 세 썸네일은 동일한 4320×2363 규격이다. 기존 카드의 표시 비율에서 크롭되는 범위를 디자이너가 확인해야 한다. 별도 디자인 수정이나 원본 재크롭을 임의로 하지 않았다.
- 김가연의 37장 상세를 포함해 모바일 이미지 안의 작은 글자·페이지 간 연결·색상·전체 스크롤 길이를 디자이너가 확인해야 한다.
