# About 페이지 구현 규격

## 기준 시안

- Figma: `Web-About` (`1309:98040`)
- 기준 폭: 1920px
- 공통 헤더: 140px
- 페이지 배경: `#F1F1F1`

## 섹션 구성

| 순서 | 섹션 | Web 기준 |
| --- | --- | --- |

## 주요 수치

- 소개 패널: x 227px, 폭 1471.5px, 높이 880px
- 포스터: 490 × 694px
- 소개 제목: 80px / 부제: 32px / 본문: 24px
- 섹션 제목: 80px
- 전시 정보 제목: 32px / 설명: 24px
- 교수·위원회 정보: 24px / 이름: 32px

## 반응형 보간 규칙

- Figma에는 Web `1920px` 프레임만 제공되어 Tab·Mobile 기준은 **미정**이다. 1020px 이하에서는 콘텐츠가 고정 패널을 넘지 않도록 소개 패널을 콘텐츠 높이로 전환하고, 전시 지도와 정보·파도형 정보 영역은 세로 흐름으로 전환한다.
- 600px 이하에서는 페이지 여백을 20px로 고정하고, 섹션 제목은 52px로 축소한다.
- 팀 카드 영역은 전용 캐러셀 안에서만 가로 스크롤·스냅·드래그·화살표 이동을 제공해 단체 사진의 비율을 보존한다. 문서 전체의 가로 오버플로는 차단한다.
- 원본 Figma PNG/SVG를 `public/assets/figma/about`에 저장하고 `unoptimized` 이미지로 출력해 재압축에 따른 선명도 저하를 막는다.
