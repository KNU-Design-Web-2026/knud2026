## 1차 구현 범위

- `PageContainer`: 모든 화면이 공유하는 최대 폭과 좌우 여백
- `Section`: 세로 리듬을 일정하게 유지하는 섹션 단위
- `SiteHeader`: Main, About, Work, Profile, Message의 공통 탐색
- `SiteFooter`: 전시 정보, 장소, 인스타그램, 저작권의 공통 노출
- 전역 토큰: Figma에서 확인한 하늘색 배경, 진한 본문색, 라임 활성색, 경계선과 Pretendard 계열 서체
- 스타일 구현: Tailwind CSS 4의 CSS-first `@theme` 설정으로 토큰과 유틸리티를 연결

## 반응형 원칙

| 구간 | 헤더 구성 | 푸터 구성 |
| --- | --- | --- |
| Web | 로고와 5개 메뉴를 한 줄 그리드로 표시 | 전시 소개·일정·메타데이터 3열 |
| Tab | 동일한 정보 구조를 더 낮은 높이와 간격으로 유지 | 2열 + 메타데이터 전폭 |
| Mobile | 로고 행과 가로 스크롤 메뉴 행으로 분리 | 한 열로 순차 표시 |

Figma Dev Mode 기준으로 2026-08-06에 2차 대조를 마쳤다. 상단 바와 하단 바는 아래 확정값을 사용한다.

- 하단 바: `#606060` 배경, 로고·전시명과 전시 정보를 2열로 배치한다. 본문은 Bold, 행간 130%를 유지한다.
- 상태: 메뉴 클릭은 노란색 `#FCD519` 텍스트와 8px 하단 바로 표시한다. 데스크톱 hover 일러스트는 Figma SVG 자산을 사용한다.

## 2026-09-04 헤더 중간 화면 QA 보정

- QA `a1c67b1d-e6a7-4ad3-b828-21fa6074dfb3`: 검토 대기. 외부 QA 상태는 자동 변경하지 않는다.
- 현재 헤더는 1350px 이상에서 가로 메뉴, 그 미만에서 햄버거 메뉴를 사용한다. 위 초기 구현 기록의 1020px 전환 기준을 대체한다.
- 1350→1920px 사이를 CSS `clamp()`로 보간한다: 좌우 여백 50→150px, 높이 120→140px, 로고 100×58→130×76px, 브랜드 간격 20→34px, 메뉴 항목 폭 118→138px, 메뉴 글자 24→28px.
- 전시명은 두 기준 모두 20px이므로 유지한다. 활성 밑줄과 hover 장식도 메뉴 크기를 따른다. 헤더 전용 여백을 사용해 다른 페이지 콘텐츠의 규격에는 영향을 주지 않는다.
- 1920px 이상은 최대 크기를 유지하며, 기존 모바일 메뉴의 색상·타이포그래피·인터랙션은 유지한다.
- 로컬 400, 1020, 1349, 1350, 1351, 1440, 1600, 1800, 1920px에서 헤더 겹침·가로 넘침 없음 확인. 배포 및 디자이너 승인 전이며 Storybook/Chromatic 검수는 미실행.
