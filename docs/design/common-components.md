## 1차 구현 범위

- `PageContainer`: 모든 화면이 공유하는 최대 폭과 좌우 여백
- `Section`: 세로 리듬을 일정하게 유지하는 섹션 단위
- `SiteHeader`: Main, About, Work, Profile, Message의 공통 탐색
- `SiteFooter`: 전시 정보, 장소, 인스타그램, 저작권의 공통 노출
- 전역 토큰: Figma에서 확인한 하늘색 배경, 진한 본문색, 라임 활성색, 경계선과 Pretendard 계열 서체
- 스타일 구현: Tailwind CSS 4의 CSS-first `@theme` 설정으로 토큰과 유틸리티를 연결

## 반응형 원칙

| 구간 | 헤더 구성 | 푸터 구성 |
| --- | --- | --- |
| Web | 로고와 5개 메뉴를 한 줄 그리드로 표시 | 전시 소개·일정·메타데이터 3열 |
| Tab | 동일한 정보 구조를 더 낮은 높이와 간격으로 유지 | 2열 + 메타데이터 전폭 |
| Mobile | 로고 행과 가로 스크롤 메뉴 행으로 분리 | 한 열로 순차 표시 |

- 상단 바: 검정 배경, 흰색 전시명과 Figma 로고를 사용한다. 1020px 이하에서는 전체 메뉴를 숨기고 메뉴 아이콘을 표시한다.
- 하단 바: `#606060` 배경, 로고·전시명과 전시 정보를 2열로 배치한다. 본문은 Bold, 행간 130%를 유지한다.
- 상태: 메뉴 클릭은 노란색 `#FCD519` 텍스트와 8px 하단 바로 표시한다. 데스크톱 hover 일러스트는 Figma SVG 자산을 사용한다.
