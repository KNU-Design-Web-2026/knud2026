## 구현 결정

- 하늘색에서 짙은 남색으로 이어지는 세로 그라데이션은 모든 기준 Frame에 동일하게 적용한다.
- 상단 바는 공통 컴포넌트를 재사용하고, 1920px와 1350px에서는 전체 메뉴를, 1020px 이하에서는 메뉴 버튼을 표시한다. 메인 페이지에서는 Figma에서 export한 단일 로고 자산과 프로젝트에 포함한 Pretendard Variable 글꼴을 사용한다.
- 메인 페이지의 기준 Frame은 히어로 영역에서 끝나므로 푸터를 렌더링하지 않는다. `SiteFooter` 컴포넌트는 이후 푸터가 포함된 화면에서 사용한다.
- 메뉴 항목은 Figma 컴포넌트의 hover 상태를 사용한다. hover 시 28px Bold 노란 텍스트, 138px×8px 하단 바, 메뉴별 원본 SVG 일러스트를 겹쳐 표시한다. 1350px 기준에서는 24px 크기를 유지한다.
- 2026-08-06 프로토타입 영상 검토 결과, Hover 중 히어로 영역을 검게 전환하지 않는다. 메뉴 글자는 색·굵기·크기를 180~220ms로, 하단 바와 일러스트는 120~240ms `cubic-bezier(0.16, 1, 0.3, 1)` 전환으로 부드럽게 표시한다. Figma MCP에는 프로토타입 전환 duration·easing 데이터가 없어, 영상에서 보이는 정적 상태와 과도한 화면 전환이 없는 동작을 기준으로 한 구현 값이다.
- 헤더 타이포그래피는 좌측 제목 `20px / 1.3 / Bold / -0.04px`, Web 메뉴 `32px / 1.3 / Regular / -0.064px`, Web→Tab 메뉴 `24px / 1.3 / Regular / -0.048px`를 기준으로 한다.
- Web 메뉴 컨테이너는 Figma 기준 `807px` 폭을 유지하고 `space-between`으로 정렬한다. 1350px 기준은 `118px` 메뉴 다섯 개와 `8px` 간격을 사용한다.
- 아트워크는 단순 축소하지 않는다. 다섯 기준 폭 모두 전체 Figma Frame PNG를 `public/assets/figma/main-frame-{폭}.png`으로 사용하고, Hero 안에서 Header 높이만큼 위로 이동해 Header 아래 영역만 노출한다. 이렇게 하면 Hero 이미지의 좌표와 하단 그림자를 동일한 원본 레이어로 유지할 수 있다.
- Tab(1020px)·Tab→Mobile(600px)·Mobile(400px)의 메뉴 버튼은 CSS 선이 아니라 각 Figma 기준 Frame에서 export한 `menu-list-{폭}.svg` 원본을 사용한다. Header는 120px/80px/60px, 로고는 100×58px/80×47px/60×35px, 제목은 20px/14px/10px으로 전환한다.
- Header의 제목은 1920px·1350px 모두 20px으로 유지한다. 메뉴 글자·메뉴 영역·최소 간격은 두 기준점(1350px: 24px/622px/8px, 1920px: 32px/807px/60px) 사이에서 `clamp()`로 선형 보간해 중간 Desktop 폭에서도 갑자기 커지지 않게 한다.
- 기존 SVG와 아트워크 그룹 PNG에는 자체 그라데이션·반투명 캔버스가 사각형으로 포함돼 하단에 분리된 그림자 경계가 생긴다. 전체 Frame PNG는 Hero 배경·아트워크·하단 그림자를 하나의 연속된 원본 레이어로 보존해 이 경계를 제거한다. 실제 Header는 해당 이미지 위의 공통 컴포넌트가 렌더링한다.

## 보간 규칙

- 1351px부터 1919px까지는 1350px와 1920px 기준의 헤더 높이·여백·로고 크기·히어로 높이를 선형 보간한다. 1920px 아트워크도 화면 폭 비율로 축소해 오른쪽이 잘리지 않게 한다. 이 구간은 적응형 동작일 뿐 픽셀 일치 검수 대상은 아니다.
- 픽셀 일치 검수는 위 표의 다섯 폭에서만 수행한다.
- Tailwind의 `max-*` 조건은 상한을 제외하므로, Figma 기준 폭인 1350px·1020px·600px·400px도 하위 규격에 포함하도록 컴포넌트 조건에는 `+0.1px` 경계값을 사용한다.
- 각 기준 Frame이 적용되는 구간에서는 원본 Frame의 가로·세로·상단 잘림값과 Hero 높이를 동일한 `vw` 비율로 함께 축소한다. 따라서 기준 폭보다 좁아질 때 아트워크가 가로만 잘리거나 세로 비율이 유지되지 않는 상태를 방지한다. 기준 Frame이 전환되는 1350px·1020px·600px·400px에서는 각 Figma 원본 규격을 우선한다.
- Header의 전체 메뉴는 Figma Web→Tab 기준인 1350px 이상에서만 표시한다. 1350px 미만에서는 48px 메뉴 버튼으로 즉시 전환해 좌측 로고와 전시 제목이 좁아지거나 세 줄로 줄바꿈되는 것을 방지한다.
- 모바일 기기마다 다른 세로 뷰포트에서는 Hero의 최소 높이를 `100dvh - Header 높이`로 보장한다. Figma 기준 Frame보다 세로가 긴 경우에도 다음 영역의 하늘색 배경이 노출되지 않고, Hero의 어두운 하단 그라데이션이 화면 끝까지 이어진다.
- 480px 이하의 넓은 모바일부터 Header를 60px·로고 60×35px·제목 10px·메뉴 30px 규격으로 전환한다. 360px 이하의 소형 모바일에서는 Header를 추가로 50px·로고 50×29.17px·제목 8px로 축소한다. 두 제목 줄은 각각 줄바꿈하지 않아 좁은 브라우저·확대 환경에서도 Header가 늘어나지 않는다. Hero의 배경색은 원본 Frame 하단과 같은 `#001A27`로 고정해 원본 이미지가 끝난 뒤에도 그림자 경계가 생기지 않게 한다.
