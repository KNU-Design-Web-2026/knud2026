## 구현 결정

- 기준 프레임은 `1920 × 1340`이며 상단 바 아래의 메인 아트워크 영역은 `1920 × 1200` 비율을 사용한다.
- 하늘색에서 짙은 남색으로 이어지는 세로 그라데이션과 원본 SVG 아트워크를 적용한다.
- 상단 바와 하단 바는 별도 공통 컴포넌트를 재사용한다. 메인 프레임에 포함된 상단 바는 아트워크 자산으로 중복 렌더링하지 않는다.
- Figma에서 추출한 개별 SVG는 `public/assets/figma/`에 저장한다. 프레임 전체 export에는 편집 캔버스 배경이 섞일 수 있어 사용하지 않는다.

## 확인 필요 항목

- Web 외 1350px·1020px·600px·400px 메인 페이지 시안이 제공되면 각 구간의 아트워크 재배치 규칙을 추가한다.
