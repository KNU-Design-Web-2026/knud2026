## 동작과 반응형 보간

- 마우스 hover, 키보드 focus, 클릭/터치로 작품 미리보기를 표시한다. Escape, focus 이탈, 지도 밖 터치로 닫는다. 실제 상세 경로를 임의로 생성하지 않는다.
- 1920px 미만의 웹은 콘텐츠 폭에 비례해 지도·이름·섹션 간격·아카이브를 축소한다.

- 지도 버튼은 44px 이상의 투명 hit area를 확보한다. Space 푸터의 작은 화면 문구는 줄바꿈을 허용한다. 다른 페이지에는 적용하지 않는다.

## 임시 작품 연결 및 hover 후속 변경

- 사용자의 임시 순차 연결 요청에 따라 Work 목록 19개를 지도 21칸에 배정했다. 마지막 두 칸은 첫 두 작품을 반복한다. `space-works.ts`에서 실제 배정으로 교체할 수 있다.
- 실제 작가 위치로 오해하지 않도록 지도 표기는 홍길동을 유지하고, 미리보기와 링크 접근성 이름에는 연결된 작가 정보를 표시한다.
- 모바일·태블릿 프레임의 좌표 나열 순서를 웹 좌표 ID에 매핑해 동일 위치의 작품이 화면 크기에 따라 바뀌지 않도록 했다.
- 웹 이름 hover/focus 시 검정·700 굵기, Work 이미지/이름/제목 카드 표시. pointer 이탈, blur, Escape 시 카드 숨김.
- 카드 opacity 240ms, 수직 이동 320ms. 퇴장 중 마지막 내용을 유지하며 카드가 포인터를 가로채지 않는다. reduced-motion에서는 즉시 전환한다.
- 태블릿·모바일 이름은 `/work/{id}` 실제 링크로 이동한다. 기존 Work 데이터 자체의 임시 이미지/제목은 그대로 사용한다.
- 브라우저에서 hover 시 검정/700 및 카드 opacity 1, 이탈 후 opacity 0/aria-hidden true를 확인했다.
