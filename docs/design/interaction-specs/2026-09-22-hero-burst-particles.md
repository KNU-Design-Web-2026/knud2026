# 메인 색면 폭발 파티클 검토안

## 최종 적용: 이중 눈 깜빡임과 장면 반응

디자이너 검토 후 꼬리 원형 유지와 색면 연쇄 폭발을 최종안으로 확정했다. 눈은 5.6초 주기에서 두 번 깜빡이고, 사자와 스프레이는 3.8초 폭발 타임라인의 최대 지점에 맞춰 짧게 반응한다. 사자는 최대 4px·0.45도, 스프레이는 최대 5px·2.2도로 제한하며 모바일에서는 이동·회전량을 절반 수준으로 줄인다. 꼬리 SVG 경로 자체에는 변형을 적용하지 않는다.

브라우저 QA에서 다섯 눈 깜빡임 뷰포트와 여섯 히어로 뷰포트를 확인했다. 꼬리 경로 불변, 사자·스프레이 반동, IGNITE 확대, 파티클 발생·종료, 가로 넘침 없음, 모션 감소 상태를 자동 검증한다.

## 최신 적용: IGNITE 중심 모션

꼬리 곡선 애니메이션은 사용자 검토에 따라 취소했다. 원본 SVG 경로를 그대로 생성하며 변형 포즈는 더 이상 포함하지 않는다. `hero_tail_poses.py`는 이전 실험의 참고 소스로만 남겨 두었으며 생성기에서 호출하지 않는다. 폐기한 꼬리 연속성 테스트는 제거하고 기존 브라우저 QA를 정적 꼬리 및 IGNITE 수축·확대·복귀 검증으로 변경했다.

IGNITE는 3.8초 주기로 1.05~1.18초 예비 수축, 1.33초 최대 확대, 1.88초 원래 크기 복귀한다. 데스크톱 최대 5%, 모바일 최대 2.5% 확대하며 별도 반동·회전·마우스 이벤트는 없다. 아래 곡선 꼬리 항목은 이전 검토 기록이다.

## 디자이너 피드백 해석

꼬리의 길이와 실루엣은 전 구간 유지한다. 기존 연소 과정은 제거하고, 폭발의 원인을 꼬리 끝이 아니라 파랑·빨강 및 노랑 폭발 색면 자체로 옮긴다. 기존 모션의 인상을 전부 바꾸지 않고 색면의 압축·확장 동작은 유지하되, 최대 확장 순간 각 색면 중심에서 각진 파편이 방사되도록 한다.

연소에 사용하던 약 1.57초가 사라지므로 전체 주기는 5.6초에서 3.8초로 단축한다. 폭발은 1.18초에 시작해 1.88초 안에 정착한다. 이후 약 1.9초의 여운을 두어 반복이 과도하게 빠른 경고 효과처럼 보이지 않게 한다.

## 구현 대상

- 꼬리 마스크·이동 불꽃·열기·접점 파편 제거
- 사자와 IGNITE 로고의 큰 반동 제거
- 세 `hero-burst` 그룹별 파티클 래퍼 생성
- 원본 팔레트와 각진 실루엣을 사용한 데스크톱 21개·모바일 12개 파편
- 3.8초 공통 타임라인과 모션 감소 정적 상태

세부 수치와 검증 기준은 저장소 루트의 `DESIGN.md`, `PRODUCT.md`를 따른다.

## 구현 및 검증

### 연속 동작 이미지 기반 곡선 꼬리

사용자가 제공한 여덟 장면의 꼬리 동작을 참고해 곡선 변형 포즈를 생성했다. 생성 단계에서 원본 폴리곤의 각 점을 중심선에 대응시키고, 중심선 방향을 연속적으로 바꾸면서 줄무늬와 끝 불꽃을 함께 이동한다. 중간 자세가 접히던 문제는 각도를 연속적으로 풀어 계산하는 방식으로 수정했다.

CSS 경로 애니메이션은 코사인 왕복 궤적에서 샘플링한 13개 자세를 24개 구간으로 연결하며, 데스크톱 3.6초·모바일 4초 주기다. 각 자세마다 easing이 재시작되던 설정과 끝 자세의 정지 구간을 제거했다. 좁은 화면의 가로 보정도 변형량에 따라 연속 적용한다. 몸통·로고·스프레이 입력은 그대로 유지한다. 실제 디자이너의 원본 애니메이션 파일을 재현한 것은 아니며 첨부 정지 이미지에서 동작을 구성한 검토안이다.

`scripts/qa-tail-continuity.mjs`는 실제 브라우저의 꼬리 경로를 한 주기 360구간으로 샘플링한다. 수정 전 중간 이동 구간의 최소/최대 이동량 비율은 약 0.0034로 정지에 가까웠고, 수정 후 1350·600·400px에서 0.59 이상이며 반복 접합점 위치 차이는 0이었다. 이는 경로 연속성 검증이며 실제 기기 FPS 측정은 아니다.

곡선 모핑은 transform 전용 애니메이션과 달리 SVG 재페인트가 필요하다. 생성 단계에서 좌표를 미리 계산하지만 실제 단말의 성능 개선을 주장하지 않는다.

### 꼬리 흔들림과 대기 동작 추가

사용자 요청으로 꼬리 고정 검토안을 발전시켜 접점 중심 좌우 2.5도(모바일 1.6도), 왕복 4.8초의 회전을 적용했다. 길이·형태·불투명도는 유지한다. 세 폭발 도형과 파편을 동일 래퍼로 묶어 서로 다른 주기의 최대 3px(모바일 1.5px) 이동을 더했다. 새 마우스 이벤트는 추가하지 않았다.

브라우저에서 SVG 회전축 좌표를 보정한 후 여섯 반응형 구간에서 접점 이동 오차 0.05px 미만, 몸통·로고 고정, 파편 두 단계 발생과 종료, 모션 감소 상태를 확인했다.

### 후속 파편과 연쇄 폭발

사용자 검토 후 색면별 폭발 간격을 130ms로 조정했다. 각 색면은 첫 폭발 150ms 뒤 크기 58%의 조각을 18도 틀어진 방향으로 한 번 더 방사한다. 후속 파편의 이동 거리는 첫 파편의 1.45배이며, 전체 주기는 3.8초를 유지한다. 데스크톱 총 33개, 모바일·세로 태블릿 총 18개로 제한한다. 마우스 입력은 스프레이에만 사용하고 히어로에는 새로운 입력 이벤트를 추가하지 않았다.

이 후속 규격이 위의 초기 파편 수와 타이밍을 대체한다.

- 원본 SVG에서 꼬리 마스크와 이동 불꽃 생성 코드를 제거하고 세 배경 색면의 실제 바운딩 박스를 기준으로 파티클 배치
- 사자 얼굴 주변 도형은 몸통과 함께 고정하고 독립 배경 도형 세 개만 애니메이션 적용
- 브라우저 캡처에서 파편이 작게 보이는 문제를 확인해 각진 조각 크기를 조정하고 불투명 유지 구간 연장
- 400·600·1020·1024 세로·1350·1920px에서 여섯 시점의 꼬리 좌표 불변, 마스크 제거, 파편 수와 발생·종료 시점, 가로 넘침 없음 확인
- reduced-motion에서 애니메이션 0개 확인, 브라우저 런타임 오류 없음
- ESLint, production build, TypeScript 검사 통과
- 로컬 시각 증거: `/tmp/knud-burst-particles`
- 디자이너의 최종 모션 검수 및 실기기 Safari·CPU/GPU 성능 측정은 별도 진행 대상
