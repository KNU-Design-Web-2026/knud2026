# 반응형 모바일 메뉴 규격

## Figma 기준

- 노드: `1633:14327` (`Tab`)
- 기준 폭: 1020px
- 헤더 높이: 120px
- 메뉴 패널: 헤더 아래 시작, 1020 × 430px

## 열린 상태

- 패널 배경: `rgba(0, 0, 0, 0.77)` + 9px backdrop blur
- 항목 순서: ABOUT, WORK, PROFILE, SPACE, MESSAGE
- 항목: 86px 높이, 32px Pretendard Regular, 중앙 정렬
- 항목 사이: 1px 흰색 구분선
- 메뉴는 헤더의 햄버거 버튼을 다시 누르거나, 메뉴 항목을 선택하거나, Escape 키를 누르면 닫힌다.

## 반응형 보간

- 600px 이하에서는 행 높이를 68px, 글자를 24px로 축소한다.
- 400px 이하에서는 행 높이를 54px, 글자를 20px로 축소한다.
- Figma에 600px·400px의 열린 메뉴 프레임은 제공되지 않아 위 수치는 Tab 기준을 보간한 구현값이다.
