# 반응형 모바일 메뉴 규격

## Figma 기준

- 노드: `1633:14327` (`Tab`)
- 기준 폭: 1020px
- 헤더 높이: 120px
- 메뉴 패널: 헤더 아래 시작, 1020 × 430px

## 열린 상태

- 패널 배경: `rgba(0, 0, 0, 0.77)` + 9px backdrop blur
- 항목 순서: ABOUT, WORK, PROFILE, SPACE, MESSAGE
- 항목: 86px 높이, 32px Pretendard Regular, 중앙 정렬
- 항목 사이: 1px 흰색 구분선
- 메뉴는 헤더의 햄버거 버튼을 다시 누르거나, 메뉴 항목을 선택하거나, Escape 키를 누르면 닫힌다.

## 전환 인터랙션

- 참고 동작: [홍익대학교 산업디자인학과 졸업전시 2024](https://hongiksidi.com/gs/2024/)
- 메뉴는 헤더 뒤쪽에서 아래로 460ms 동안 내려오며, 열림 상태에서는 다시 위로 이동하며 닫힌다.
- 햄버거의 세 선은 닫힌 상태에서 동일한 간격을 유지하고, 열리면 위·아래 선이 중앙에서 교차해 닫기(X) 아이콘이 된다. 가운데 선은 축소·페이드 처리한다.
- 메뉴 항목은 패널 이동이 시작된 뒤 100ms부터 40ms 간격으로 위에서 아래 순서로 나타난다. 닫을 때는 즉시 역방향 전환해 입력을 막는다.
- 포인터가 메뉴 항목을 가리키면 행 전체가 160ms 동안 `#FCD519`으로 채워지고, 텍스트는 검정색으로 전환한다. 같은 강조는 키보드 focus에도 적용한다.
- `prefers-reduced-motion: reduce` 환경에서는 전역 축소 모션 규칙을 따라 즉시 전환한다.

## 반응형 보간

- 600px 이하에서는 행 높이를 68px, 글자를 24px로 축소한다.
- 400px 이하에서는 행 높이를 54px, 글자를 20px로 축소한다.
- Figma에 600px·400px의 열린 메뉴 프레임은 제공되지 않아 위 수치는 Tab 기준을 보간한 구현값이다.
