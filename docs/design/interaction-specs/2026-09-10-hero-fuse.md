# 메인 히어로 도화선 모션

상태: 구현 후 디자인 검토 요청. QA Hub 의견은 자동 완료하지 않는다.

## 의도와 동작

주변 도형을 별의 반짝임이 아니라 페인트·폭죽의 폭발로 표현한다.
사자의 도화선 끝에서 불이 몸통 방향으로 이동하며 도화선이 지워진다.
점화 직후 사자가 살짝 움츠렸다 펴지고 IGNITE 로고와 주변 도형이 반응한다.
사자 자체를 제거하거나 화면 전체를 번쩍이게 하지는 않는다.

| 시간(12초 반복) | 표현 |
| --- | --- |
| 0–1.8초 | 원본 배치로 대기 |
| 1.8–4.8초 | 불꽃 이동과 도화선 소진 |
| 약 4.8–5.9초 | 사자 반동, 로고 펄스, 주변 도형 팽창 및 작은 파편 |
| 약 6.7–7.4초 | 도화선 복구 |
| 이후 | 다음 점화까지 대기 |

시간·팽창률은 디자이너 검토 후 조절 가능한 초깃값이다.

## 구현

- 기존 Figma SVG의 레이어와 좌표를 재사용한다. 원본 파일은 변경하지 않는다.
- `scripts/generate-hero-motion.py`가 5개 반응형 프레임의 ID를 구분하고 모션 클래스와 도화선 마스크를 삽입한다.
- 생성 결과는 `hero-scenes.generated.ts`에 저장한다. 재생성: `python3 scripts/generate-hero-motion.py`.
- 400px 프레임은 기존 PNG 표시 높이 860px에 맞춰 하단을 잘라 표시한다.
- 서버 컴포넌트가 신뢰된 저장소 SVG 문자열을 렌더링한다. 사용자 입력은 HTML에 삽입하지 않는다.
- CSS 마스크와 offset-path로 도화선 소진 및 불 이동을 연결하고 transform/opacity로 반동을 표현한다.
- 스프레이 입력·입자 생성·Canvas 렌더링 코드는 변경하지 않는다.

## 접근성과 비용

- 우측 하단 버튼으로 반복 모션을 멈추거나 재개할 수 있다.
- `prefers-reduced-motion: reduce`에서는 원본 정적 배치로 표시한다.
- 화면 밖 또는 백그라운드 탭에서는 재생을 멈춘다.
- 별도의 RAF 루프와 Canvas 입자는 추가하지 않았다. 다만 SVG 마스크에는 페인트 비용이 발생할 수 있고 5개 SVG가 HTML에 포함된다. 따라서 성능 최적화라고 주장하지 않는다.
- 기존 스프레이 성능 측정과 비교할 때는 히어로 모션의 켜짐/꺼짐 조건도 통제해야 한다.

## 검증 기록 (2026-09-10)

- `pnpm type-check`, `pnpm lint`, `pnpm build` 통과.
- 로컬 브라우저에서 400·600·1020·1350·1920px 프레임 선택과 가로 넘침 여부 확인.
- 400px 및 1350px 화면 캡처로 배치와 도화선 소진 단계 확인. 기존 불꽃 잔상 제거.
- 정지 버튼 클릭 후 애니메이션의 playState가 paused인 것을 확인.
- 모션 감소 에뮬레이션에서 애니메이션 0개와 정지 버튼 숨김 확인 후 에뮬레이션 복원.
- DevTools 시간 고정은 시각 검사에만 사용하고 새로고침으로 복원했다.
- CPU/GPU 프로파일링, 실기기 Safari 확인, 디자이너 승인은 아직 진행하지 않았다.
