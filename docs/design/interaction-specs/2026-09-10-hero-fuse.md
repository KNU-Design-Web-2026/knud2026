## 숨은 헤더 영역의 스프레이 경계 제거 (검토 요청)

헤더는 opacity로 숨겨지지만 문서의 spacer는 남아 있어, 천천히 위로 스크롤하면 배경만 보이는 상단에 Canvas·입력 영역이 없었다. 메인 hero를 헤더 높이만큼 위로 확장하고 높이도 같은 만큼 늘려 기존 문서 하단 위치를 유지한다. 아트워크는 hero 내부에서 헤더 높이만큼 내려 기존 화면 좌표를 보존한다. Canvas와 입력 영역은 확장된 hero 전체를 공유한다.

고정 헤더 z-50은 hero보다 위에 유지해 보일 때 내비게이션 입력과 검은 배경을 우선한다. 숨겨지면 기존 pointer-events-none에 따라 아래 입력 영역으로 전달한다. 헤더 표시 규칙·다른 페이지·입자 생성 로직은 변경하지 않는다. Canvas 크기가 커지는 비용은 다음 성능 측정에 포함해야 한다.

`scripts/qa-hero-header-boundary.mjs`는 5px씩 천천히 되올리는 스크롤, 숨은 상단 입력 대상, 실제 Canvas 알파 픽셀, 헤더 복귀 시 입력 우선권을 검사한다.

## 2026-09-11 디자이너 피드백 반영

- 12초 반복·3초 소진이 느리고 정적으로 느껴진다는 의견에 따라 반복 5.6초, 소진 약 1.57초로 단축했다.
- 대체 별 모양을 없애고 원본 SVG의 빨강·노랑·파랑 불꽃 경로를 재사용한다. 꼬리와 통합된 경로는 원래 빨간 불꽃 실루엣으로 잘라 추출한다. 불꽃은 약 58%까지 작아졌다가 마지막 순간 짧게 커지며 사라진다.
- 도화선 삭제 경로와 불 이동 시간을 맞추고 삭제 폭을 76에서 58 기준 좌표 단위로 줄였다. 원래 불꽃 자리는 윤곽선까지 마스킹해 잔상을 방지한다.
- 불꽃에 0.14초 단위의 작은 형태 변화와 0.32초 주기의 국소 불티를 추가한다. 실사 불꽃이나 물리 연소 시뮬레이션이 아니라 원본 그래픽 스타일을 유지한 연소 표현이다.
- 사자·로고·폭발 도형은 점화 전과 복구 후에도 작게 움직인다. 폭발 순간 사자 최대 1.05배, 로고 1.032배, 주변 도형 1.2배로 대비를 키운다.
- 스프레이 질감·수명·입력 로직은 변경하지 않는다. 추가 모션의 CPU/GPU 비용은 이번 시각 QA에서 측정하지 않았다.

## 구현

### 2026-09-11 추가 요청 — 과감한 순간 폭발

5.6초 주기와 연소 표현은 유지하고 33~43% 구간에 움직임을 집중한다. PC는 폭발 도형을 0.8배로 압축한 뒤 최대 1.4배·7도 회전으로 펼친다. 사자는 세로 0.92배로 움츠린 뒤 16 좌표 px 위로 반동하며 최대 가로 1.065·세로 1.09배가 된다. IGNITE는 최대 1.06배 확대 후 짧게 반대 방향으로 흔들리고, 파편 이동 거리는 기존의 1.65배로 확장한다. 이후 작은 오버슈트로 원래 배치에 복귀한다.

600px 이하에서는 도형 1.23배·4도, 사자 이동 5 좌표 px·세로 최대 1.045배, 로고 1.025배, 파편 거리 1.1배로 낮춘다. SVG 좌표 단위이므로 실제 화면 크기에 따라 비례 축소된다. 화면 전체 점멸은 추가하지 않았으며 모션 감소 설정에서는 정적 상태를 유지한다. 검증 스크립트는 폭발 시점의 실제 변환 행렬로 데스크톱 강화와 모바일 제한을 확인한다.

- 기존 Figma SVG의 레이어와 좌표를 재사용한다. 원본 파일은 변경하지 않는다.
- `scripts/generate-hero-motion.py`가 5개 반응형 프레임의 ID를 구분하고 모션 클래스와 도화선 마스크를 삽입한다.
- 생성 결과는 `hero-scenes.generated.ts`에 저장한다. 재생성: `python3 scripts/generate-hero-motion.py`.
- 400px 프레임은 기존 PNG 표시 높이 860px에 맞춰 하단을 잘라 표시한다.
- 서버 컴포넌트가 신뢰된 저장소 SVG 문자열을 렌더링한다. 사용자 입력은 HTML에 삽입하지 않는다.
- CSS 마스크와 offset-path로 도화선 소진 및 불 이동을 연결하고 transform/opacity로 반동을 표현한다.
- 스프레이 입력·입자 생성·Canvas 렌더링 코드는 변경하지 않는다.

## 접근성과 비용

- 이전 사용자 요청에 따라 별도 모션 정지 UI는 표시하지 않는다.
- `prefers-reduced-motion: reduce`에서는 원본 정적 배치로 표시한다.
- 화면 밖 또는 백그라운드 탭에서는 재생을 멈춘다.
- 별도의 RAF 루프와 Canvas 입자는 추가하지 않았다. 다만 SVG 마스크에는 페인트 비용이 발생할 수 있고 5개 SVG가 HTML에 포함된다. 따라서 성능 최적화라고 주장하지 않는다.
- 기존 스프레이 성능 측정과 비교할 때는 히어로 모션의 켜짐/꺼짐 조건도 통제해야 한다.

# 사자 눈 깜빡임 추가 (2026-09-11)

원본 일반 눈(Vector_55)을 클리핑 영역으로 사용하여 파란 눈꺼풀과 검은 감은 눈 선만 추가한다. 반대편 폭죽 눈은 유지하며 원본 SVG는 수정하지 않는다. 생성 스크립트를 통해 다섯 반응형 장면에 같은 비율로 적용한다.

5.6초 공통 주기에서 29~36%에 폭발 전 눈을 감았다 뜨고, 86~95%에 짧게 두 번 깜빡인다. 별도 타이머 없이 기존 CSS 재생·정지 상태를 공유하며 모션 감소 설정에서는 눈을 뜬 상태로 유지한다. `scripts/qa-hero-blink.mjs`로 5개 화면의 열림·닫힘과 모션 감소를 검증한다.
# 곡선 회전과 연소 강화 (2026-09-11)

불꽃의 고정 회전을 제거하고 경로 접선에 따른 `offset-rotate: auto`를 적용한다. 시작 접선 각도(-64.98도)의 반대 각도를 보정하여 최초 Figma 불꽃 방향은 유지한다. 꺾이는 구간에서는 불꽃과 불티가 같이 회전한다.

진행 반대 방향으로 짧게 튀는 불티를 3개에서 6개로 늘린다. 주기 후반 28~33.9%에서 밝기(최대 1.28배)를 점진적으로 강화한다. 원본 불꽃 실루엣, 5.6초 주기, 눈 깜빡임과 모션 감소 설정은 유지한다. 작은 불꽃 그룹에만 밝기 필터를 적용하며 성능 개선으로 주장하지 않는다.

## 불꽃 크기와 중심 유지 후속 조정 (2026-09-11)

기존 최소 0.58배 축소와 중첩 회전으로 불꽃이 작아지고 꼬리 중심에서 흔들리는 문제를 조정했다. 연소 중 크기는 원본 대비 1.15~1.28배를 유지한다. 별도 좌우 회전은 제거하고 경로 접선 회전만 남긴다. 미세 변화는 세로 0.98~1.03배로 제한하며 불티와 밝기로 연소감을 유지한다. 5개 규격의 연소 시점에서 크기 하한과 추가 회전 없음이 브라우저 검증 기준이다.
## 불꽃 크기 미세 축소 (2026-09-11)

크기가 과하게 부각된다는 후속 피드백으로 직전 연소 키프레임의 크기를 모두 90%로 줄였다. 현재 범위는 원본 대비 1.035~1.152배이며 경로 회전·불티·밝기·세로 미세 변화는 그대로 유지한다. 이전 1.15~1.28배 규격은 이 값으로 대체한다.
## 도화선 접점과 상승 불티 (2026-09-11)

불꽃의 시각적 중심 대신 원본 불꽃과 꼬리가 만나는 뿌리를 경로 시작점과 변형 기준으로 사용한다. 마스크와 불꽃은 같은 경로를 공유하며, 이전 시작점과 새 뿌리 사이의 짧은 꼬리 조각도 함께 지워 잔상을 방지한다. 접점에는 작은 탄 가장자리와 밝은 불씨를 둔다.

불티는 별도의 동일 경로 그룹에 배치하고 회전을 고정한다. 따라서 꼬리가 꺾여도 불티는 화면 위쪽으로 향한다(사자 전체의 미세 반동은 공유). 6개 불티의 지속시간과 시작 위상을 분산하고 불꽃의 미세 팽창 간격도 다르게 구성한다. 물리 시뮬레이션이나 무작위 매 프레임 생성은 아니며, 반복 CSS 모션으로 연소감을 표현한다.

5개 화면·30개 시점에서 불꽃 뿌리와 경로 접점의 화면 거리 1px 미만, 불티의 상승 방향, 기존 폭발과 모션 감소를 검사한다. 기존 5.6초 주기와 불꽃 크기 범위를 유지한다. 이 검증은 기능·시각 QA이며 성능 비교 측정은 아니다.
## 불꽃 횡폭과 소진 경계 보정 (2026-09-11)
