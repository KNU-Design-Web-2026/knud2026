# 메인 스프레이 인터랙션 규격

## 목적

메인 Hero에서 클릭·드래그에 반응하는 스프레이가 전시 그래픽의 에너지를 보강하되, 입력 지연과 과도한 렌더링을 만들지 않도록 한다.

## 입력과 상태

- 대상: 마우스를 지원하는 Hero 영역
- 시작: 주 포인터 버튼을 누른다.
- 이동: 마지막 스탬프 위치와 현재 포인터 위치 사이에 간격 기반으로 스탬프를 추가한다.
- 종료: 포인터를 놓거나 취소한다.
- 색상: 새 스트로크를 시작할 때마다 노랑 → 빨강 → 아이보리 → 연두 순서로 변경한다.
- 유지 시간: 스탬프는 1.8초간 유지하고, 이후 0.6초 동안 사라진다.
- 도포 강도: 펜의 유효한 pressure는 보조 입력으로 사용한다. 마우스에서는 pressure를 실제 힘으로 해석하지 않고, 누른 시간과 이동 속도로 중심 도포의 밀도를 보정한다.

## 형태 규칙

- 스프레이는 중심 도포층, 가장자리 안개층, 외곽 비산층으로 렌더링한다. 중심 도포층은 주변 입자보다 더 진하고 두껍게 보이도록 한다.
- 방향성 꼬리나 지속적인 잔상은 렌더링하지 않는다. 일부 정지 또는 저속 지점에만 짧은 드립을 허용한다.
- 각 스탬프의 비산 입자 형태는 생성 시 확정해, 페이드아웃 중에도 형태가 깜빡이지 않게 한다.

## 성능 경계

- 스탬프 개수로 드래그 경로를 자르지 않으며, 생성 후 2.4초가 지난 스탬프만 제거한다.
- 장치 픽셀 비율은 2를 넘지 않는다.
- 스프레이 중이거나 남은 스탬프가 있을 때만 animation frame을 실행한다.
- 포인터 이벤트마다 즉시 렌더링하지 않는다. 최신 입력값을 저장하고 animation frame에서 보간·생성·렌더링을 수행한다.
- reduced motion 및 정밀 포인터 미지원 환경에서는 기능을 비활성화한다.
