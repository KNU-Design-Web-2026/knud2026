# 메인 스프레이 인터랙션 규격

## 목적

메인 Hero에서 클릭·드래그에 반응하는 스프레이가 전시 그래픽의 에너지를 보강하되, 입력 지연과 과도한 렌더링을 만들지 않도록 한다.

## 입력과 상태

- 대상: 마우스를 지원하는 Hero 영역
- 시작: 주 포인터 버튼을 누른다.
- 이동: 마지막 스탬프 위치와 현재 포인터 위치 사이를 6px 간격으로 보간해 끊김 없이 스탬프를 추가한다.
- 종료: 포인터를 놓거나 취소한다.
- 색상: 새 스트로크를 시작할 때마다 노랑 → 빨강 → 아이보리 → 연두 순서로 변경한다.
- 유지 시간: 각 스탬프는 생성 시점부터 3초간 유지하고, 이후 1초 동안 사라진다. 따라서 드래그 경로는 먼저 뿌려진 부분부터 자연스럽게 지워진다.

## 형태 규칙

- 스프레이는 입력 기기와 관계없이 동일한 크기로 렌더링한다.
- 중심 도포는 반투명한 짧은 타원과 조밀한 입자로 구성하고, 가장자리는 낮은 불투명도의 미스트 입자로 불규칙하게 흩어진다.
- 색상과 관계없이 스탬프는 서로를 꼬리로 연결하지 않으며, 생성 시간이 지난 개별 스탬프만 사라진다.

## 성능 경계

- 최대 스탬프 수는 180개로 제한한다.
- 장치 픽셀 비율은 2를 넘지 않는다.
- 스프레이 중이거나 남은 스탬프가 있을 때만 animation frame을 실행한다.
- reduced motion 및 정밀 포인터 미지원 환경에서는 기능을 비활성화한다.
