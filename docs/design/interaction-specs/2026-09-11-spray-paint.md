# 미세 스프레이와 흘러내리는 페인트

- 상태: 구현 후 디자이너 검토 요청 대기
- 브랜치: `feat/hero-spray-interaction`
- 기준 코드: `84f2bb8` (`main`, 기존 성능 최적화 브랜치 미포함)
- 참고: 사용자가 첨부한 ROCK STAR / MUSIC 그래피티 이미지

## 변경 이유와 표현

기존 미세 입자의 최대 반지름은 `(0.7 + 2.8) × 1.9 = 6.65px`였다. 큰 원이 개별적으로 보이고 드립은 완성된 다각형으로 즉시 나타났다. 참고 자료처럼 채워진 획, 거친 미세 경계, 아래로 길어지는 드립을 표현한다. 이미지의 검정색 대신 기존 전시 팔레트를 사용한다.

| 조정 항목 | 현재 값 (CSS px / ms) |
| --- | --- |
| 중심 도포 반지름 | 획 방향 25~29px, 수직 방향 19~23px |
| 중심 불투명도 | 0.86, 겹친 획은 더 진해짐 |
| 미세 입자 반지름 | 0.25~1.15px |
| 입자 수 | 스탬프당 96개, 가까운 경계 76개 + 외곽 20개 (일부 획은 외곽 6개를 후방 비산으로 사용) |
| 경로 스탬프 간격 | 기존 12px 유지 |
| 드립 시작 | 0.22px/ms 이하 저속 또는 정지 상태가 240ms 지속 |
| 드립 생성 간격·상한 | 최소 420ms 간격, 살아 있는 드립 최대 8개 |
| 드립 길이·굵기 | 38~92px / 1.3~2.6px |
| 흐름 시간 | 900~1200ms, 처음 빠르고 끝으로 갈수록 감속 |
| 수명 | 도포 시점 기준 2800ms 유지 + 800ms 페이드 |

미세 입자와 외곽 좌표는 생성 때 확정한다. 새 프레임에서는 형태를 재추첨하지 않는다. 드립은 회전한 도포 타원의 아래쪽 내부에서 시작하며 화면의 아래 방향으로 흐른다. 정지 상태의 한 스탬프에 여러 드립이 반복 생성되지 않는다. 마우스를 놓으면 새 드립 생성은 중단되고 이미 생성된 드립은 도포층과 함께 사라진다. 짧은 클릭이나 빠르게 지나간 위치에는 드립이 생기지 않는다.

### 2026-09-11 추가 검토 — 후방 비산과 수명 연장

참고 이미지의 획 바깥쪽에 드물게 튄 점을 반영한다. 이동 중 생성한 스탬프의 38%에서 외곽 입자 중 6개를 진행 방향 반대편 부채꼴에 배치한다. 획 반지름의 1.5~2.85배 거리로 퍼지되 가까운 곳에 더 많이 분포하며 반지름 상한은 1.15px를 유지한다. 정지 클릭에는 방향을 부여하지 않는다. 입자는 찍힌 위치에 남으므로 움직이는 연기 같은 꼬리가 생기지 않는다.

사용자 추가 요청으로 총 수명을 2400ms에서 3600ms로 늘렸다. 스탬프당 입자 수는 그대로지만 같은 입력에서 화면에 남는 스탬프 수는 증가할 수 있으므로, 이후 성능 측정에서는 변경된 수명을 함께 기록한다.

## 입력과 접근성

헤더를 제외한 기존 `main-spray-zone`을 사용한다. 색상은 노랑 → 빨강 → 아이보리 → 주황 → 파랑으로 순환한다. 정밀 포인터가 없는 터치 환경과 `prefers-reduced-motion`에서는 도포하지 않는다. 실행 중 환경 설정 변경, 창 포커스 이탈, 문서 비노출 때는 입력과 캔버스를 정리한다. 포인터 캡처 손실·취소도 입력 종료로 처리한다.

## 검증과 측정 경계

- 순수 모델 테스트: 미세 입자 상한, 시드 재현성, 방향별 드립 연결 위치, 시간별 드립 길이, 페이드 수명.
- 브라우저: `scripts/qa-spray-paint.mjs`로 실제 마우스 입력을 보내 1350·1920px 드립 성장과 수명 종료, 400px 터치 비활성화, 모션 감소 설정 변경을 확인한다. PNG·WebM·JSON 결과를 저장한다.
- 이 기록은 기능·시각 QA이며 성능 최적화 전후 비교 측정이 아니다. 질감·도포 크기·입자 수·드립 비용이 달라졌으므로 기존 성능 수치와 직접 비교하지 않는다.
- 현재 경로 보간·스탬프 생성은 기존 main처럼 포인터 이벤트에서 수행한다. 프레임 단위 입력 소비, 스프라이트 캐시, 풀링 등 기존 성능 브랜치의 변경은 이번에 이식하지 않았다. 디자이너 검수 후 이 디자인을 기준으로 동일 입력 시나리오를 다시 측정한다.

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
SPRAY_QA_URL=http://localhost:3002 \
SPRAY_QA_OUTPUT=/absolute/path/to/evidence \
node scripts/qa-spray-paint.mjs
```

이 명세는 [이전 스프레이 규격](./2026-08-12-main-spray.md)의 색상·형태·드립 규칙을 갱신한다. [ADR-0003](../../architecture/adr/0003-use-pressure-assisted-layered-spray-rendering.md)은 제안 문서이며 그 안의 성능 계획 전체가 구현되었다는 의미는 아니다.
