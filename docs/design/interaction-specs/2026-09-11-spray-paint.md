# 미세 스프레이와 흘러내리는 페인트

- 상태: 구현 후 디자이너 검토 요청 대기
- 브랜치: `feat/hero-spray-interaction`
- 기준 코드: `84f2bb8` (`main`, 기존 성능 최적화 브랜치 미포함)
- 참고: 사용자가 첨부한 ROCK STAR / MUSIC 그래피티 이미지

## 변경 이유와 표현

기존 미세 입자의 최대 반지름은 `(0.7 + 2.8) × 1.9 = 6.65px`였다. 큰 원이 개별적으로 보이고 드립은 완성된 다각형으로 즉시 나타났다. 참고 자료처럼 채워진 획, 거친 미세 경계, 아래로 길어지는 드립을 표현한다. 이미지의 검정색 대신 기존 전시 팔레트를 사용한다.

| 조정 항목 | 현재 값 (CSS px / ms) |
| --- | --- |
| 중심 도포 반지름 | 획 방향 25~29px, 수직 방향 19~23px |
| 중심 불투명도 | 단색 면 없음, 입자별 알파 0.55~0.95가 겹치며 진해짐 |
| 미세 입자 반지름 | 기준 질감 0.2~1px, 스탬프 확대 후에도 1.15px 미만 |
| 입자 수 | 질감당 2200개: 중심 1800개 + 외곽 400개 (후방 비산 시 외곽 24개 재배치) |
| 경로 스탬프 간격 | 기존 12px 유지 |
| 드립 시작 | 이동 거리 90~180px마다 후보 지정 후 180~420ms 지연 / 저속·정지 240ms 유지도 지원 |
| 드립 생성 간격·상한 | 최소 420ms 간격, 살아 있는 드립 최대 8개 |
| 드립 길이·굵기 | 38~92px / 1.3~2.6px |
| 흐름 시간 | 900~1200ms, 처음 빠르고 끝으로 갈수록 감속 |
| 수명 | 도포 시점 기준 2800ms 유지 + 800ms 페이드 |

미세 입자와 외곽 좌표는 생성 때 확정한다. 새 프레임에서는 형태를 재추첨하지 않는다. 드립은 회전한 도포 타원의 아래쪽 내부에서 시작하며 화면의 아래 방향으로 흐른다. 한 스탬프에 여러 드립이 반복 생성되지 않는다. 짧은 클릭에는 드립이 생기지 않지만, 이동 중 칠한 위치에 예약된 드립은 커서가 떠나거나 마우스를 놓은 뒤에도 시작될 수 있다. 드립과 칠은 같은 수명을 공유한다.

### 2026-09-11 추가 검토 — 다공성 입자층으로 교체

사용자의 검정 스프레이 획 사진을 기준으로, 불투명도 0.86의 다각형 면을 제거했다. 중심은 절단된 가우시안 분포의 미세 입자 1800개로 칠하고 외곽 400개는 더 넓게 분산한다. 블러나 균일한 원형 테두리를 사용하지 않는다. 겹칠수록 짙어지지만 입자 사이 빈틈과 넓은 저밀도 외곽이 남는다. 중간 획 드립과 3.6초 수명은 유지한다.

늘어난 입자를 매 프레임 개별 그리기 하지 않도록 12개 질감 변형 × 후방 비산 유무의 로컬 좌표 템플릿을 공유한다. 색상별로 2배 해상도의 작은 캔버스에 최초 한 번 그린 뒤 각 스탬프는 크기·방향·페이드만 적용해 `drawImage`로 재사용한다. 캐시는 컴포넌트 Effect 범위에 있고 최대 120개(24종 × 팔레트 5색), RGBA 픽셀 기준 약 52MiB 상한이다. 모든 스탬프가 별도 이미지 버퍼를 갖지는 않는다.

이 캐시는 새 질감의 렌더링 비용을 제어하기 위한 이번 브랜치의 구현이며, 기존 성능 최적화 브랜치를 병합한 것이 아니다. 성능 개선율은 측정하지 않았으며 첫 질감 생성 비용과 캐시 메모리도 후속 측정 대상이다. 이전의 96개 입자 기준과는 디자인과 작업량이 달라 직접 성능 비교하지 않는다.

### 2026-09-11 추가 검토 — 중간 획에서도 흐르는 페인트

정지 지점에만 집중되던 흐름을 획 중간에도 분산한다. 입력 이벤트 횟수 대신 실제 생성한 12px 간격 스탬프의 이동 거리를 누적하여 90~180px마다 후보를 지정한다(12px 단위로 올림). 후보가 정해질 때 180~420ms의 지연을 한 번 추첨한다. 프레임마다 확률을 재추첨하지 않는다.

정지·이동 드립은 420ms 생성 간격, 최대 8개, 기존 드립 중심에서 최소 56px 이격을 공유한다. 칠한 지 900ms 이상 지난 후보는 새로 흐르지 않도록 무시한다. 빠른 긴 획에서도 드립이 한꺼번에 몰리지 않고, 지나간 위치에서 차례대로 흐르도록 한 시각적 규칙이며 물리 유체 시뮬레이션은 아니다. 기존 3.6초 수명과 입자 질감은 유지한다.

### 2026-09-11 추가 검토 — 후방 비산과 수명 연장

참고 이미지의 획 바깥쪽에 드물게 튄 점을 반영한다. 최초 구현은 이동 중 생성한 스탬프의 38%에서 외곽 입자 중 6개를 진행 방향 반대편 부채꼴에 배치했다(다공성 질감 교체 후에는 24개). 획 반지름의 1.5~2.85배 거리로 퍼지되 가까운 곳에 더 많이 분포한다. 정지 클릭에는 방향을 부여하지 않는다. 입자는 찍힌 위치에 남으므로 움직이는 연기 같은 꼬리가 생기지 않는다.

사용자 추가 요청으로 총 수명을 2400ms에서 3600ms로 늘렸다. 스탬프당 입자 수는 그대로지만 같은 입력에서 화면에 남는 스탬프 수는 증가할 수 있으므로, 이후 성능 측정에서는 변경된 수명을 함께 기록한다.

## 입력과 접근성

헤더를 제외한 기존 `main-spray-zone`을 사용한다. 색상은 노랑 → 빨강 → 아이보리 → 주황 → 파랑으로 순환한다. 정밀 포인터가 없는 터치 환경과 `prefers-reduced-motion`에서는 도포하지 않는다. 실행 중 환경 설정 변경, 창 포커스 이탈, 문서 비노출 때는 입력과 캔버스를 정리한다. 포인터 캡처 손실·취소도 입력 종료로 처리한다.

## 검증과 측정 경계

- 순수 모델 테스트: 미세 입자 상한, 시드 재현성, 방향별 드립 연결 위치, 시간별 드립 길이, 페이드 수명.
- 브라우저: `scripts/qa-spray-paint.mjs`로 실제 마우스 입력을 보내 1350·1920px 드립 성장과 수명 종료, 400px 터치 비활성화, 모션 감소 설정 변경을 확인한다. PNG·WebM·JSON 결과를 저장한다.
- 이 기록은 기능·시각 QA이며 성능 최적화 전후 비교 측정이 아니다. 질감·도포 크기·입자 수·드립 비용이 달라졌으므로 기존 성능 수치와 직접 비교하지 않는다.
- 현재 경로 보간·스탬프 생성은 기존 main처럼 포인터 이벤트에서 수행한다. 기존 성능 브랜치의 변경은 이식하지 않았고 이번 다공성 질감에 맞는 제한된 텍스처 캐시를 추가했다. 디자이너 검수 후 이 디자인을 기준으로 동일 입력 시나리오를 다시 측정한다.

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
SPRAY_QA_URL=http://localhost:3002 \
SPRAY_QA_OUTPUT=/absolute/path/to/evidence \
node scripts/qa-spray-paint.mjs
```

이 명세는 [이전 스프레이 규격](./2026-08-12-main-spray.md)의 색상·형태·드립 규칙을 갱신한다. [ADR-0003](../../architecture/adr/0003-use-pressure-assisted-layered-spray-rendering.md)은 제안 문서이며 그 안의 성능 계획 전체가 구현되었다는 의미는 아니다.
