# 오픈 전 MESSAGE 기록 정리

- 반영 시각: 2026-10-19 11:11:21 KST
- 대상: KNUD 2026 Messages 운영 DB의 `public.public_letters`
- 요청: 이전 메시지는 화면에서 제거하고 이준섭이 작성한 예시 네 건만 유지한다.

## 반영 결과

- 공개 메시지 14건 중 기존 기록 10건을 `hidden_at`으로 숨겼다. 영구 삭제는 하지 않았다.
- 보존한 ID: `16` 김지언, `17` 이서윤, `18` 김세직, `19` 김서은. 발신자는 모두 이준섭이며 본문·작성 시각은 변경하지 않았다.
- 숨긴 ID: `4, 5, 6, 7, 9, 10, 12, 13, 14, 15`. 이준섭 이름으로 작성된 과거 테스트 메시지 ID `4`도 제외했다.
- 기존에 숨겨져 있던 5건은 그대로 유지했다. 전체 행 19건 중 공개 4건, 숨김 15건이다.
- DB 재조회, 로컬 `/api/letters` HTTP 200과 MESSAGE 화면에서 예시 네 건만 표시되는 것을 확인했다.

## 운영 경계

- 일반 서비스 키에는 UPDATE 권한이 없어 로그인된 Supabase 관리자 SQL Editor에서 트랜잭션으로 처리했다. 서비스 키 권한이나 RLS 정책을 변경하지 않았다.
- 코드 배포와 별개로 이미 DB에 적용된 조치다. 이 문서를 병합하거나 코드를 되돌려도 DB 상태가 바뀌지 않는다.
- 필요 시 관리자 권한으로 이번 대상 ID와 `hidden_at = '2026-10-19T02:11:21.685941+00:00'`을 함께 확인한 뒤 숨김을 해제할 수 있다. 기존에 숨겨진 기록까지 일괄 복구하지 않는다.
- 추가 편지 작성과 10월 20일 오전 9시 예약 공개 설정은 변경하지 않았다.
