# ADR-0004: 허용된 QA Hub에 현재 경로만 전달한다

- 상태: 승인됨
- 결정일: 2026-09-01
- 적용 범위: 배포된 전시 사이트의 디자인 검수 iframe

## 배경

디자이너는 QA Hub 안에서 전시 사이트의 Profile, Work 등 여러 페이지를 이동한 뒤 의견을 남긴다. iframe은 다른 도메인에서 실행되므로 Hub는 내부 페이지 이동을 직접 읽을 수 없다. 이 상태에서는 Profile에서 남긴 의견이 처음 화면인 `/`에 저장되어 메인 화면에 표시될 수 있다.

## 결정

전시 사이트는 `NEXT_PUBLIC_QA_HUB_ORIGIN`으로 지정한 QA Hub가 iframe 부모일 때만 현재 `pathname`을 `postMessage`로 전달한다.

- Hub가 `knud.qa/subscribe-route` 메시지를 보내면, 전시 사이트는 origin과 부모 window를 확인한다.
- 확인된 Hub에만 `knud.qa/route-state` 메시지로 현재 pathname을 전달한다.
- 이 Bridge는 UI를 렌더링하거나 클릭을 가로채지 않는다.
- 환경 변수가 없거나 일반 브라우저 탭에서 열린 경우 아무 동작도 하지 않는다.

## 결과

QA Hub는 디자이너가 이동한 실제 페이지 경로를 기준으로 코멘트를 저장하고, 같은 경로에서만 마커를 표시할 수 있다. 전달 정보는 공개 페이지의 경로로 제한하며, 로그인 정보나 QA 데이터는 전시 사이트에서 전달하지 않는다.
