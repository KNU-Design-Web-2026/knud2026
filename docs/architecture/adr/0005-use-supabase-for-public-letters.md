# ADR-0005: 공개 롤링페이퍼 저장소로 Supabase PostgreSQL을 사용한다

- 상태: 제안됨
- 결정일: 2026-09-15
- 적용 범위: MESSAGE 페이지의 공개 편지 조회·작성

## 배경

MESSAGE 화면은 지금까지 브라우저 상태에만 편지를 추가해 새로고침과 다른 방문자 화면에 반영되지 않았다. 편지는 익명으로 작성되며 저장 직후 공개되어야 하고, 반복 요청 방지와 향후 운영자 숨김 처리도 필요하다.

## 결정

- Next.js Route Handler가 공개 편지 조회와 작성을 처리한다.
- 편지와 요청 제한 기록은 Supabase PostgreSQL에 저장한다.
- 브라우저는 Supabase에 직접 접근하지 않고 `/api/letters`만 호출한다.
- Service Role Key는 서버 전용 환경 변수로만 관리한다.
- 작성 요청은 서버에서 다시 검증하고, 원본 IP 대신 서버 비밀값으로 해시한 식별자만 제한 기록에 저장한다.
- 10분 동안 같은 식별자의 성공 요청을 최대 5건으로 제한한다.
- 부적절한 편지는 삭제 대신 `hidden_at`으로 숨길 수 있도록 데이터 모델을 둔다.

## 결과

편지는 저장 성공 응답을 받은 뒤 현재 화면의 목록 맨 앞에 즉시 표시되고, 이후 방문자도 같은 DB 목록을 조회한다. Supabase 장애나 환경 변수 누락 시 작성 성공처럼 보이지 않으며 사용자에게 재시도 안내를 표시한다.

운영 Supabase 프로젝트와 환경 변수는 배포 전에 별도로 연결해야 한다. 관리자 인증과 숨김 UI는 다음 작업 범위로 남긴다.
