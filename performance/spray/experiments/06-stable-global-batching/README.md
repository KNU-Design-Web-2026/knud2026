# 실험 06 — 안정 구간 전체 배치

## 가설

fade가 시작되지 않은 스탬프는 동일 알파를 사용하므로 색상과 16단계 알파별로 전체를 묶어 그리면 프레임당 fill 호출을 크게 줄일 수 있다고 예상했다. 마지막 600ms의 fading 스탬프는 기존 방식으로 유지했다.

## 결과

| CPU | run | Render p95 | Frame interval p95 | Peak active stamps |
| --- | ---: | ---: | ---: | ---: |
| Native | 1 | 10.1ms | 17.6ms | 733 |
| Native | 2 | 10.7ms | 17.8ms | 733 |
| Native | 3 | 10.1ms | 17.7ms | 733 |
| CPU 4× | 1 | 35.3ms | 40.4ms | 682 |
| CPU 4× | 2 | 36.9ms | 42.5ms | 661 |
| CPU 4× | 3 | 36.5ms | 41.7ms | 681 |

Native 프레임 간격은 17.6~17.8ms로 일부 좋아졌지만, Render p95와 CPU 4× 결과는 모두 기존보다 악화되었다.

## 판정

기각한다. 수천 개의 원을 하나의 복잡한 경로로 합칠 때 경로 fill 비용이 커져 호출 수 감소 이점을 상쇄했다. 렌더링 표현을 바꾸는 대신, 스프레이 폭에 비해 과도하게 촘촘한 공간 샘플링을 조정하는 방향으로 전환한다.
