# 실험 07 — 24px 공간 샘플링

## 가설

스프레이 본체 폭이 약 61~95px인데 경로를 12px마다 찍어 동일 영역을 과도하게 중복 렌더링하고 있었다. 입자 82개, 반지름, 알파, 외곽선, 드립 수식은 유지하고 스탬프 간격만 24px로 조정하면 질감을 유지하면서 활성 스탬프 수를 줄일 수 있다.

- 고정 seed 캔버스 비교: SSIM 0.975079, PSNR 27.292540dB

## 판정

성능은 유효하지만 시각 비교에서 스프레이 띠의 밀도가 조금 낮아졌다. 최종안으로 바로 채택하지 않고 20px 간격을 추가 측정해 품질과 성능의 균형점을 찾는다.

`native/`, `4x/`에는 3회 원시 JSON과 대표 trace가 있고, `visual-diff/`에는 캔버스·전체 화면 PNG, MP4, baseline diff가 있다.
