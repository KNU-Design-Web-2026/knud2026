# Experiment 08 — 공간 샘플링 간격 20px

## 가설

스프레이의 파티클 공식과 수명은 유지하면서 포인터 경로의 공간 샘플링 간격만 12px에서 20px로 넓히면, 시각적 인상은 유지하고 Fast drag에서 동시에 다시 그리는 스탬프 수를 줄일 수 있다.

## 변경 변수

- 변경: 거리 보간 간격 12px → 20px
- 유지: 스탬프당 파티클 수, 반지름, 알파, 가장자리 분포, 드립 확률·모양, 수명
- 함께 반영한 비시각 최적화: 프레임별 배열·좌표 객체 제거, Canvas 경계 캐시, 스탬프별 삼각함수 중복 제거

## 최종 headed Chrome 결과

| CPU | 시나리오 | Render p95 | Frame interval p95 | Peak active stamps |
|---|---|---:|---:|---:|
| Native | Fast drag | 4.60ms | 12.10ms | 440 |
| Native | Decay | 4.75ms | 11.90ms | 440 |
| 4× | Fast drag | 19.40ms | 27.05ms | 440 |
| 4× | Decay | 19.15ms | 26.65ms | 440 |

기준 구현의 Fast drag는 Native 7.55ms / 20.30ms / 733개, 4× CPU 27.05ms / 38.00ms / 685.5개였다. 첫 실행을 워밍업으로 제외한 4회 중앙값이다.

## 시각 비교

- seed: `20260908`
- SSIM: `0.976297`
- PSNR: `27.78139dB`
- 스프레이 영역 평균 밝기 변화: 약 `-0.7%`
- 스프레이 영역 평균 채도 변화: 약 `-3.5%`

픽셀은 완전히 동일하지 않지만, 파티클 공식 자체를 단순화하지 않았고 실제 전후 이미지와 영상에서 스프레이의 거친 경계와 드립 질감을 함께 검토했다.

## 판정

**채택.** 이전 실험보다 효과가 반복적으로 크고, 24px 실험보다 시각적 변화가 작았다. 브라우저 실행 모드가 섞인 결과는 결론에서 제외하고, 기준과 동일한 headed Chrome 50회를 다시 수행한 결과만 최종 비교에 사용한다.
