# 기각 실험 03 — 활성 스탬프 기반 60fps 페이싱

- 실행일: 2026-09-08
- 환경: 로컬 production build, Chrome, 1512×982, DPR 2, Native CPU
- 조건: 활성 스탬프 240개 이상에서 최소 16ms 간격으로 Canvas 렌더

## 가설

16단계 Path2D 렌더러가 120Hz 주기에 진입했다가 일부 프레임을 놓치는 현상을 막기 위해, 무거운 구간만 기존 렌더러의 실효 속도와 같은 약 60fps로 제한하면 프레임 간격을 안정화할 수 있다고 예상했다.

## 결과

| 실행 | Pointer moves | Peak stamps | Canvas frames | Render p95 | Frame interval p95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Run 01 | 320 | 733 | 727 | 3.4ms | 31.1ms |
| Run 02 | 320 | 733 | 735 | 3.2ms | 31.6ms |
| Run 03 | 320 | 733 | 734 | 3.2ms | 30.9ms |

## 기각 이유

가변 주사율 환경의 rAF 간격이 항상 정확히 8.3ms가 아니어서 단순한 16ms 문턱은 일부 프레임을 24~32ms 뒤로 미뤘다. 렌더 횟수는 줄었지만 프레임 간격이 더 나빠졌고, 가벼운 구간과 무거운 구간 사이에 새로운 전환 규칙까지 생겼다.

프레임률을 인위적으로 제한하지 않고 렌더링과 객체 관리의 실제 작업량을 줄이는 방향으로 전환한다.
