# 실험 05 — 스탬프 단위 알파 배치

## 가설

82개 입자의 밀도와 반지름을 유지하고 알파만 16단계로 양자화한 뒤, 같은 스탬프 안의 입자를 한 경로로 묶으면 `fill()` 호출 수를 줄일 수 있다고 예상했다.

## 결과

Native `fast-drag` 3회 결과는 다음과 같다.

| run | Render p95 | Frame interval p95 | Peak active stamps |
| ---: | ---: | ---: | ---: |
| 1 | 9.8ms | 28.8ms | 733 |
| 2 | 10.2ms | 28.8ms | 733 |
| 3 | 9.9ms | 28.8ms | 733 |

기존 배포 중앙값인 Render p95 7.6ms, Frame interval p95 20.3ms보다 모두 악화되었다.

## 판정

기각한다. `fill()` 횟수는 줄었지만 스탬프마다 복잡한 다중 서브패스를 채우는 비용이 더 컸다. 다음 실험에서는 fade가 없는 안정 구간만 전체 스탬프 단위로 묶어 경로 수 자체를 더 크게 줄인다.
