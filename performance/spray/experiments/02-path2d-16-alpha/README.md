# 기각 실험 02 — 16단계 알파 Path2D

- 실행일: 2026-09-08
- 환경: 로컬 production build, Chrome, 1512×982, DPR 2, Native CPU
- 시나리오: Fast drag, 방향 판단용 1회와 반복 3회

## 가설

입자 82개의 위치와 반지름은 유지하고 알파만 16단계 표시값으로 묶으면, 스탬프마다 약 82번 발생하던 `fill()`을 최대 16번으로 줄일 수 있다고 예상했다.

## 기각 이유

JavaScript 렌더 p95는 절반 이하로 줄었지만 Canvas 프레임 간격이 두 군집으로 갈라지고 20ms 초과 구간이 크게 늘었다. CPU에서 빨리 반환된 Path2D 명령이 GPU·컴포지터 단계에 불규칙한 부담을 넘긴 것으로 추정되며, 최종 판단에는 trace 분석이 더 필요하다.

사용자가 체감하는 프레임 간격을 악화시키므로 최종 구현으로 채택하지 않는다.
